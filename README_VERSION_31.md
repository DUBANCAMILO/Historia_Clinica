# Versión 31 — Órdenes médicas, agenda automática y flujo de inicio

- Se retiró Órdenes externas del menú lateral.
- Receta pasó a llamarse Órdenes médicas en la interfaz.
- Las órdenes se consultan desde el icono de acciones de cada paciente.
- La impresión de órdenes separa medicamentos, laboratorios, paraclínicos y órdenes médicas en hojas independientes.
- Las citas de primera vez y control tienen fecha editable dentro de la orden médica.
- Al guardar una orden con cita, esta se crea automáticamente en Agenda.
- Tipos incluidos: primera vez por nefrología, primera vez por medicina interna, controles por ambas especialidades y control de resultados de laboratorios.
- Agenda permite atender y retirar la cita, marcar no asistió, cancelar e imprimir constancia.
- Al iniciar la aplicación se solicita login; después del acceso se abre Inicio.
- Historia clínica empieza en blanco al entrar desde el menú o desde Inicio.
- Se amplió el catálogo inicial de medicamentos y laboratorios, manteniendo la posibilidad de escribir o importar catálogos propios.
- Se agregó configuración de papel A4, Carta o térmico, orientación y márgenes para todas las impresiones.
- Se mejoraron acciones rápidas y visibilidad de botones en pantallas pequeñas.
