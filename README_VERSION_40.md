# Versión 40 — Impresión unificada y gestión ampliada

- Las órdenes médicas manuales ahora se imprimen con la misma cabecera clínica profesional que Historia y Pacientes: logo, datos del médico, paciente/documento, fecha, diagnóstico y QR junto al título.
- Medicamentos, laboratorios externos, paraclínicos, otras órdenes e indicaciones mantienen hojas separadas.
- Desde el icono de Órdenes médicas de Pacientes se puede imprimir cada orden manual individual con el mismo formato clínico.
- Se amplió la gestión manual: filtro por estado, cambio rápido de estado, copia de una orden como nueva independiente, contadores de actividad, edición, guardado, limpieza, impresión y eliminación confirmada.
- Se mejoró la presentación general de navegación, accesos, encabezado de Pacientes, controles de formularios y tarjetas del módulo de órdenes.
- Las estadísticas de pacientes ya calculan el mes actual y evitan porcentajes NaN cuando la base está vacía.
