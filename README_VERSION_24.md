# Versión 24 — guardado en historia y receta ordenada

- El botón de la pestaña de receta guarda el paquete principal en la historia clínica y actualiza el paciente; ya no usa el guardado independiente como destino principal.
- El botón se identifica como `Guardar en Pacientes`.
- La impresión separa medicamentos, laboratorios, paraclínicos y órdenes médicas, aunque se soliciten desde un único cuadro.
- Se agregó la categoría de órdenes médicas para citas, controles, remisiones e interconsultas.
- Se retiró la etiqueta y captura de CUPS; se conservan códigos institucionales internos editables del catálogo.
- Se eliminaron concentración, seguimiento, órdenes pendientes y documentos externos de la historia.
- La receta conserva presentación y dosis como campos separados.
- Los catálogos integrados muestran códigos internos legibles y los catálogos personalizados pueden editarse desde Configuración.
- Se corrigió el guardado usando el paquete actual para no depender de un render intermedio.
