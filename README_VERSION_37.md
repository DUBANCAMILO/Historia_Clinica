# Versión 37 — Impresión de Pacientes corregida

- La impresión desde el icono del ojo en Pacientes ahora imprime únicamente la historia completa.
- Se eliminó de esa impresión el contenedor adicional de órdenes separadas que generaba páginas vacías o desordenadas.
- Las órdenes separadas continúan disponibles exclusivamente desde el icono de Órdenes médicas.
- Se conservaron las clases necesarias de la vista para mantener la cuadrícula y los campos anchos correctamente alineados.
- La capa de impresión mantiene el documento aislado de menús, modal y controles.
