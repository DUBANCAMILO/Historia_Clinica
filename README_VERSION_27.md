# Versión 27 — pestañas clínicas rediseñadas

- Historia clínica y Receta/órdenes ahora se presentan como pasos clínicos visibles.
- Cada pestaña muestra número, icono, descripción y progreso.
- Se indica cuándo una sección ya tiene información.
- Se muestra el paciente, documento y número de historia en el contexto de navegación.
- Navegación responsive para escritorio, tablet y móvil.
- Se conserva el rediseño responsive general de v26.
